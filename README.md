# MoMents – Pregnancy & Postpartum Support App

MoMents is a mobile application designed to support women throughout their journey from pregnancy to post-delivery. The app includes features such as fetal development tracking, vitals monitoring, and personalized insights to improve user engagement and awareness.

It also allows users to share their journey with loved ones, creating a connected and supportive experience.

## Tech Stack
- React Native / Expo
- JavaScript
- REST APIs
- Firebase / Backend services
